# ShieldChain Financial — Responsive Prototype

This is a static front-end prototype for review. Open `index.html` in a modern browser.

## Included
- Responsive layouts for phones, tablets, laptops and desktop
- Animated CSS vault / growing money stack concept
- Start Here onboarding section
- Service, security, planned crypto asset, founder story, demo dashboard and feedback sections
- "Ask Minute Man" demo assistant with simple sample answers
- Accessibility basics including keyboard focus, labels, status announcements and reduced-motion handling

## Not live / not connected
- No account registration or authentication
- No database or backend
- Feedback is not transmitted or saved
- Minute Man is a local demo assistant, not a live AI connection
- No real trading, crypto wallets, payments, custody or payouts
- No domain registration, hosting, security certification or legal approval

## Run locally
Open `index.html` directly in your browser. For a simple local server, run:
`python -m http.server 8000`
and visit `http://localhost:8000`.
